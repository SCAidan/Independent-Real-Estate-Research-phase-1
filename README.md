# Independent Real Estate Research — basic website

Five static pages: Home, Why an Appraisal, The Process, Our Standards, and Contact. No build step or accounts required to run the static files.

## GitHub or static hosting
Upload the CONTENTS of the supplied ZIP to the repository root. index.html, styles.css, script.js and the remaining HTML pages should be at the root. No assets folder is required; the house artwork is inline SVG and the favicon is included.

## Content
Reorganized and condensed from the public HomePage.x, whyget.x, whatis.x, Ethics.x, and contact.x pages at https://irer.appraiserxsites.com/ on October 14, 2026 (Pacific time). Business contact details and service categories are retained. General educational material is summarized rather than copied word for word. No new testimonials, staff names, license numbers, prices, or turnaround commitments have been invented. The house drawing is decorative and is not a photograph of the office or a client property.

## Existing systems
Order an Appraisal, Client Login, Ask a Question, tutorial, sample PDF, and original terms link to the existing provider site. They require that provider site to remain available. This rebuild does not migrate authentication, report delivery, appraisal orders, or form processing. No new form backend is needed.

## Check before replacing the current site
Confirm the published phone, fax, and office address remain correct. The source page's email address rendered as an encoded string; it has intentionally not been reproduced. Use the working original contact form link or add a confirmed email address later. The original business owner should review service copy and standards before public replacement.

## Verification
All five pages were checked for local file paths, internal anchors, and duplicate IDs. JavaScript syntax passed Node's syntax check. Browser rendering was not tested in the build environment. No customer forms were submitted.
